
# **Boulanger**
*/bulɑ̃ʒe/*

noun

##### a person who makes bread and cakes, especially as a trade.


Boulanger is a Neoforge mod for Minecraft 1.21. This mod introduces realistic baking concepts and science. Furthermore, this mod introduces realistic flour milling mechanics.
